## Файловый менеджер

Приложение для поиска файлов на компьютере по заданному расширению, разработанное на C# с использованием Windows Forms.

## Цель проекта

Разработать приложение с графическим интерфейсом для поиска файлов по заданным критериям, отображения результатов в виде дерева каталогов и управления процессом поиска.

## Описание проекта

Файловый менеджер — программа, позволяющая искать файлы в выбранной директории и всех её вложенных папках.

Результаты поиска отображаются в виде дерева каталогов, что обеспечивает удобный просмотр найденных файлов.

## Возможности

- Поиск файлов по заданному расширению (`txt`, `docx`, `pdf` и др.).
- Выбор начальной директории для поиска.
- Рекурсивный поиск во всех вложенных папках.
- Отображение найденных файлов в виде дерева каталогов.
- Подсчёт количества найденных и просмотренных файлов.
- Отображение времени выполнения поиска.
- Возможность остановки поиска в любой момент.
- Графический интерфейс Windows Forms.

## Используемые технологии

- **Язык программирования:** C#
- **Платформа:** .NET
- **Графический интерфейс:** Windows Forms
- **Среда разработки:** Visual Studio

## Принцип работы

1. Пользователь запускает приложение.
2. Указывает начальную директорию для поиска.
3. Вводит расширение файлов.
4. Нажимает кнопку «Поиск».
5. Программа проверяет файлы в выбранной директории и всех её подпапках.
6. Найденные файлы отображаются в древовидной структуре.
7. Отображается время, затраченное на поиск.
8. После завершения выводится количество найденных и общее количество просмотренных файлов.

Поиск можно прервать в любой момент с помощью кнопки «Остановить».
